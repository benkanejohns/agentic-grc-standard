# The Agentic GRC Standard

The operating principles and domain grounding every GRC agentic system is built to, written to be read by the system itself.

Published alongside [the Agentic GRC manifesto](https://agenticgrc.io/) at [agenticgrc.io/standard](https://agenticgrc.io/standard/).

## Usage

Paste the "Part 1: Operating principles" section of [`Agentic-GRC-Standard.md`](./Agentic-GRC-Standard.md) directly into a GRC agentic system's system prompt. "Part 2: Domain grounding" is reference knowledge the agent should be grounded on, structured knowledge beats raw prompting, so prefer retrieving against it over pasting it wholesale.
